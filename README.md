# API and curl guide

Base URL:

```bash
export BASE_URL=http://localhost:8080
```

Responses use JSON. Monetary fields are integer paise (`15000` = ₹150.00).
Times are RFC 3339. IDs are UUIDs generated by the server.

## Health

```bash
curl --fail-with-body "$BASE_URL/health"
```

## Register a driver and vehicle

The vehicle may support `AC`, `DC`, or both. Both are needed for AC-to-DC fallback.

```bash
DRIVER_RESPONSE=$(curl --fail-with-body -sS \
  -X POST "$BASE_URL/v1/drivers" \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "Asha Rao",
    "email": "asha@example.com",
    "registration_number": "KA01EV1234",
    "supported_connector_types": ["AC", "DC"]
  }')

echo "$DRIVER_RESPONSE" | jq
export DRIVER_ID=$(echo "$DRIVER_RESPONSE" | jq -r '.id')
```

## Register a station with connectors

```bash
STATION_RESPONSE=$(curl --fail-with-body -sS \
  -X POST "$BASE_URL/v1/stations" \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "MG Road Charging Hub",
    "latitude": 12.9756,
    "longitude": 77.6066,
    "connectors": [
      {"type": "AC", "power_kw": 22},
      {"type": "DC", "power_kw": 60}
    ]
  }')

echo "$STATION_RESPONSE" | jq
export STATION_ID=$(echo "$STATION_RESPONSE" | jq -r '.id')
export AC_CONNECTOR_ID=$(echo "$STATION_RESPONSE" | jq -r '.connectors[] | select(.type=="AC") | .id')
export DC_CONNECTOR_ID=$(echo "$STATION_RESPONSE" | jq -r '.connectors[] | select(.type=="DC") | .id')
```

## Take a connector out of service

Valid manual statuses are `OUT_OF_SERVICE` and `AVAILABLE`. An `IN_USE`
connector returns HTTP 409.

```bash
curl --fail-with-body \
  -X PATCH "$BASE_URL/v1/connectors/$AC_CONNECTOR_ID/status" \
  -H 'Content-Type: application/json' \
  -d '{"status":"OUT_OF_SERVICE"}'
```

## Bring a connector back into service

```bash
curl --fail-with-body \
  -X PATCH "$BASE_URL/v1/connectors/$AC_CONNECTOR_ID/status" \
  -H 'Content-Type: application/json' \
  -d '{"status":"AVAILABLE"}'
```

## Add a promo code

```bash
curl --fail-with-body \
  -X POST "$BASE_URL/v1/promo-codes" \
  -H 'Content-Type: application/json' \
  -d '{
    "code": "EV20",
    "discount_percent": 20,
    "valid_from": "2026-01-01T00:00:00Z",
    "valid_until": "2027-01-01T00:00:00Z",
    "max_uses": 100
  }'
```

`max_uses` may be omitted for unlimited use.

## Start a session

The API searches inside `radius_km` and atomically claims the nearest free,
compatible connector. The location below is the driver's current location.

```bash
SESSION_RESPONSE=$(curl --fail-with-body -sS \
  -X POST "$BASE_URL/v1/sessions" \
  -H 'Content-Type: application/json' \
  -d "{
    \"driver_id\": \"$DRIVER_ID\",
    \"requested_type\": \"AC\",
    \"latitude\": 12.9716,
    \"longitude\": 77.5946,
    \"radius_km\": 5,
    \"promo_code\": \"EV20\"
  }")

echo "$SESSION_RESPONSE" | jq
export SESSION_ID=$(echo "$SESSION_RESPONSE" | jq -r '.id')
```

To demonstrate AC-billed-on-DC, first take the station's AC connector out of
service, then run the start request above. The response will contain:

```json
{
  "physical_connector_type": "DC",
  "billed_connector_type": "AC"
}
```

Omit `promo_code` when no promo should be applied. An invalid, expired, deleted,
or exhausted promo returns HTTP 422 and does not claim a connector.

## End a session and receive the bill

```bash
curl --fail-with-body \
  -X POST "$BASE_URL/v1/sessions/$SESSION_ID/end" \
  -H 'Content-Type: application/json' \
  -d '{"energy_delivered_kwh":11}'
```

The completed session includes:

- `base_cost_paise`: progressive tariff with the minimum enforced
- `discount_paise`: snapshotted promo percentage applied to the base
- `final_cost_paise`: amount due
- `energy_delivered_kwh` and `ended_at`

Ending an already completed session returns HTTP 409.

## Driver session history

Returns active and completed sessions, newest first.

```bash
curl --fail-with-body \
  "$BASE_URL/v1/drivers/$DRIVER_ID/sessions"
```

## Station session history

Returns active and completed sessions, newest first.

```bash
curl --fail-with-body \
  "$BASE_URL/v1/stations/$STATION_ID/sessions"
```

## Delete a promo code

Deletion deactivates the promo and preserves audit history. Existing sessions
retain the discount snapshotted when they started.

```bash
curl --fail-with-body \
  -X DELETE "$BASE_URL/v1/promo-codes/EV20"
```

Successful deletion returns HTTP 204 with no response body.

## Useful edge-case demos

No station in radius:

```bash
curl -i \
  -X POST "$BASE_URL/v1/sessions" \
  -H 'Content-Type: application/json' \
  -d "{
    \"driver_id\": \"$DRIVER_ID\",
    \"requested_type\": \"AC\",
    \"latitude\": 28.6139,
    \"longitude\": 77.2090,
    \"radius_km\": 1
  }"
```

Invalid promo:

```bash
curl -i \
  -X POST "$BASE_URL/v1/sessions" \
  -H 'Content-Type: application/json' \
  -d "{
    \"driver_id\": \"$DRIVER_ID\",
    \"requested_type\": \"AC\",
    \"latitude\": 12.9716,
    \"longitude\": 77.5946,
    \"radius_km\": 5,
    \"promo_code\": \"DOES_NOT_EXIST\"
  }"
```
